# Plugin Template

Use this template to create a custom video block for the platform.

---

## Folder Structure

```
my-plugin/
  plugin.json      ← Plugin metadata (name, category, icon, color)
  schema.json      ← Defines your block's fields (shown in Properties Panel)
  src/
    Scene.tsx      ← Your Remotion animation component
    index.ts       ← Entry point — don't change this
  dist/
    index.esm.js   ← Compiled bundle (generated by 'npm run build')
  package.json     ← Add extra npm deps here (optional)
```

---

## Step 1 — Rename your plugin

In `plugin.json`, change:
- `"id"` → unique slug like `"crypto-ticker"` (lowercase, hyphens only)
- `"name"` → display name like `"Crypto Ticker"`
- `"category"` → one of: `content`, `data`, `visual`, `interactive`, `social`, `media`, `layout`, `other`
- `"color"` → hex color for the block card in the editor
- `"description"` → one-line description

---

## Step 2 — Define your fields in schema.json

Each field in `"properties"` becomes an input in the Properties Panel.

**Supported editor types:**
| editor      | when to use               |
|-------------|---------------------------|
| `text`      | short text                |
| `textarea`  | long text / multiline     |
| `number`    | numeric input             |
| `slider`    | number with min/max range |
| `color`     | color picker              |
| `toggle`    | boolean on/off switch     |
| `select`    | dropdown from fixed list  |
| `image`     | image URL + file upload   |

**Example field:**
```json
"price": {
  "type": "number",
  "title": "Price",
  "editor": "slider",
  "editorConfig": { "min": 0, "max": 10000, "step": 100, "unit": "$" },
  "default": 99
}
```

Use `"ui".sections` to group fields into collapsible sections.

---

## Step 3 — Build your animation in Scene.tsx

The platform always passes these props — don't change the function signature:

```tsx
export default function MyScene({ data, theme, animation }) {
  const frame = useCurrentFrame();       // current frame (0 → durationInFrames)
  const { fps } = useVideoConfig();      // frames per second

  // data = your schema fields (title, color, etc.)
  // theme = 'dark_modern' | 'light_minimal' | 'bold_vibrant' | 'corporate'
  // animation = { enter: seconds, hold: seconds, exit: seconds }
}
```

**Useful utilities (already available, no install needed):**
```tsx
import { useCurrentFrame, useVideoConfig, interpolate, spring } from 'remotion';
import { BaseScene, getThemeColors, extractCustomization } from '../../shared/plugin-utils';
```

- `interpolate(frame, [0, 30], [0, 1])` — linear animation between values
- `spring({ frame, fps, config: { damping, stiffness } })` — physics-based spring
- `getThemeColors(theme)` → `{ background, backgroundSecondary, text, textSecondary, accent, accentSecondary, border }`
- `BaseScene` — wraps your content with background, padding, alignment

---

## Step 4 — Add extra dependencies (optional)

If your block needs a library (e.g. `d3`, `chart.js`, `gsap`):

1. Add it to `package.json` under `"dependencies"`
2. Run `npm install` to install it locally
3. The library will be compiled into your bundle in Step 5

**Do NOT add these** — they are provided by the platform:
- `react`, `react-dom`, `remotion`, `@remotion/player`

---

## Step 5 — Build and package your plugin

The platform requires a **pre-compiled** bundle. Build it on your machine before creating the ZIP:

```bash
# 1. Install dependencies (first time, or when you add new ones)
npm install

# 2. Compile your plugin into dist/index.esm.js
npm run build

# 3. Create the installable ZIP (includes src/ + dist/ + plugin.json + schema.json)
npm run package
```

This produces `my-plugin.zip` in the current folder.

> **Why pre-build?** The platform runs on serverless (Vercel). Compiling happens on your machine — it's instant, handles any library size, and works 100% of the time regardless of platform limits.

### What goes in the ZIP
| File | Required |
|------|----------|
| `plugin.json` | ✅ yes |
| `schema.json` | ✅ yes |
| `src/Scene.tsx` | ✅ yes |
| `dist/index.esm.js` | ✅ yes (run `npm run build`) |
| `package.json` | optional |

---

## Step 6 — Install your plugin

1. In the editor, open the Block Library sidebar
2. Click **"Install Plugin (.zip)"** at the bottom
3. Select the ZIP you created — it validates and installs in under 2 seconds
4. Your block appears in the **"Custom Plugins"** section of the block library

---

## Tips

- Use `BaseScene` — it handles background, alignment, border, shadow automatically
- Test animations locally: open `src/Scene.tsx` in any Remotion project
- Keep Scene.tsx focused — no file I/O, no shell commands, no `eval()`
- The `animation.enter` phase is when your block appears, `animation.hold` is the main duration, `animation.exit` is when it leaves
- If you update your plugin, just re-run `npm run build && npm run package` and re-install
